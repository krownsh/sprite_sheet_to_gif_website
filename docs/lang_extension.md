# 多語系擴展計畫 (lang.js)

為了完善 Google Ads 所需內容，我們擴充了 `libs/lang.js` 中的鍵值。

## 1. 導航與首頁
- `nav.about`: 關於我們
- `nav.faq`: 常見問題
- `nav.blog`: 教學部落格
- `hero.title`: 釋放你的創意，客製化專屬像素精靈
- `hero.desc`: Pixel Sprite Studio 是專為獨立遊戲開發者與藝術愛好者設計的強大工具。

## 2. 靜態頁面
- `info.privacy`: 隱私權政策全文
- `info.terms`: 服務條款全文
- `info.contact`: 聯絡我們方式

## 3. 部落格內容
- `blog.p1.title`: 像素製作入門
- `blog.p1.content`: (文章內容摘要)
- ... (以此類推)
