# 像素精靈工廠 網站架構說明 (Google Ads 優化版)

本文件詳述為了通過 Google Ads 審核而調整後的網站架構與內容佈局。

## 1. 架構原則
- **一頁式 (SPA)**：維持原本單檔 HTML 結構，透過 JavaScript 進行區塊顯示/隱藏。
- **SEO 優化**：補足專業內容區塊，提升網站權重與文字密度。
- **法律合規**：加入隱私權政策、服務條款等 Google Ads 必要頁面。

## 2. 導航與連結
- **頁首 (Header)**：加入 About, FAQ, Blog 文章入口。
- **頁尾 (Footer)**：加入所有法律與資訊連結。

## 3. 內容分佈
- **Hero Section**：首頁首屏加入品牌介紹，降低工具屬性首印。
- **Blog Section**：包含至少 4 篇原創像素藝術相關教學與文章。
- **Legal/Info Section**：集中管理靜態資訊內容。

## 4. 技術實作
- 使用 `info.js` 管理視圖切換。
- 使用 `Lang.js` 處理多語系。
- 原核心邏輯 `app.js` 保持不變。
